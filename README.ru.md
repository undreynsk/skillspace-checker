# skillspace-checker

[English](README.md) | **Русский**

CLI-утилита для проверки домашних заданий по Python в школе на Skillspace:
загружает работы, ожидающие проверки, запускает код ученика на примерах из условия
в изолированном Docker-контейнере и даёт преподавателю принять работу прямо из консоли.

## Как это работает

- Логинится через форму на сайте (headless Chromium, Playwright) и обращается к внутреннему API Skillspace.
- Тесты - это таблицы примеров "Ввод / Вывод" из условия задачи.
- Каждый тест запускается в одноразовом контейнере `python:3.14-slim`: без сети, 64 MB памяти,
  лимит 2 секунды, файловая система только для чтения. Подсказки `input()` подавляются,
  поэтому сравнивается только результат.
- Для каждой работы показывает условие, код ученика и вердикт, затем спрашивает
  `Accept? [y/N]` и необязательный комментарий.

## Требования

- Windows с WSL2 Ubuntu и Docker Engine внутри неё (`sudo apt install docker.io`)
- uv

## Запуск

    cp .env.example .env    # заполнить URL, id школы, email и пароль
    uv run playwright install chromium
    uv run checker.py

`auth.py` - вспомогательный скрипт, которым изучалось API: логинится в видимом браузере
и записывает запросы в `logs/`, маскируя учётные данные.
